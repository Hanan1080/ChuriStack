# CHURISTACK 🌸
**Stack Your Style, Celebrate Your Tradition.**

CHURISTACK is a modern Bengali traditional bangle boutique website that celebrates colorful culture, beauty, and elegance.

### ✨ Features
- English & Bengali language toggle
- Traditional and colorful UI design
- Product collections and best sellers
- Add to Cart functionality
- Product category filters
- Customer reviews and FAQ section
- WhatsApp order button
- Fully responsive design

### 🛠️ Technologies
- HTML5
- CSS3
- JavaScript

### 🚀 Deployment
Hosted using GitHub Pages.
